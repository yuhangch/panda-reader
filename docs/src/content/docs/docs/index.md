Panda Reader works with a local library or with a supported feed provider. Its article plugin
system can repair and clean publisher pages before they reach the reader.

## Sync a feed library

Connect a local library without a server, or use Panda Reader as a desktop client for Miniflux
and FreshRSS.

[Set up a provider →](./providers/)

## Make publisher pages readable

Install community plugins or build your own with declarative rules or WebAssembly.
