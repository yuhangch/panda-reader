# Panda Bamboo theme extension for Zed

This light theme adapts Panda Reader's **Panda Bamboo** palette: warm gray-white surfaces, dark ink text, and bamboo-green accents. The extension author is @yuhangch.

## Install as a dev extension

In Zed, open the Extensions page, choose **Install Dev Extension**, and select this directory (`extras/zed`). Zed looks for `extension.toml` at the selected directory's root. Then open the Theme Selector and choose **Panda Bamboo**.

## Install as a local theme file

Alternatively, copy [`themes/Panda Bamboo.json`](themes/Panda%20Bamboo.json) into Zed's local `themes` directory and restart Zed.

- Windows: `%APPDATA%\Zed\themes\`
- macOS and Linux: `~/.config/zed/themes/`

Create the `themes` directory if it does not exist.
